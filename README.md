# سیمرغ — دستیار هوشمند مشاور تحصیلی

وب‌اپ موبایل‌محور (PWA) برای **مشاور تحصیلی مستقل**: مدیریت چند دانش‌آموز، منابع و فصل‌بندی، برنامه هفتگی، پیگیری روزانه، آزمون زمان‌دار با بانک سوال اختصاصی، محتوای لینکی و گزارش ماهانه.

- تقویم **جلالی**، هفته از **شنبه**، منطقه زمانی **Asia/Tehran**
- رابط فارسی و RTL
- موتور برنامه‌ریزی **قطعی**؛ AI **اختیاری** با fallback قطعی
- Excel-first: ایمپورت دومرحله‌ای + خروجی برنامه و گزارش

---

## پیش‌نیازها

- [Bun](https://bun.sh/) (تست‌شده با `1.4.2`)
- Node.js 20 یا بالاتر (تست‌شده با `22`)

پروژه از **PGlite** (Postgres تعبیه‌شده) استفاده می‌کند؛ نیازی به نصب جداگانه Postgres نیست.

---

## اجرا

```bash
bun install
bun run db:seed
bun run dev
```

سپس <http://localhost:3000> را باز کنید.

اگر داده نمونه از قبل وجود دارد و می‌خواهید از صفر شروع کنید:

```bash
bun run db:reset
bun run db:seed
```

> داده‌ها در `.data/pg` ذخیره می‌شوند و در `.gitignore` هستند.

---

## اجرای production (سرور ساده)

```bash
cp .env.example .env
# PORT و HOST را در .env تنظیم کنید
bun install
bun run build
bun run start
```

`bun run start` فایل `.env` را می‌خواند و Next.js را روی `HOST` و `PORT` اجرا می‌کند. همین یک فایل تنظیمات برای جابه‌جایی روی هر سرور کافی است.

برای دسترسی بقیه دستگاه‌ها در همان شبکه:

```text
http://<IP-سرور>:<PORT>
```

مثلاً اگر IP سرور `172.19.224.15` و پورت `3001` باشد:

```text
http://172.19.224.15:3001
```

نکته مهم: در حالت HTTP ساده، `COOKIE_SECURE=false` بماند؛ وگرنه مرورگر کوکی ورود را ذخیره نمی‌کند. اگر بعداً دامنه و HTTPS گذاشتید، آن را `true` کنید.

> در حال حاضر PGlite همان دیتابیس مرکزی روی همین سرور است. برای مقیاس بیشتر بعداً به PostgreSQL مهاجرت می‌کنیم.

## متغیرهای محیطی

فایل `.env.example` را به `.env` کپی کنید (اختیاری برای اجرای محلی):

```bash
cp .env.example .env
```

| متغیر | توضیح |
|---|---|
| `PGLITE_DATA_DIR` | مسیر داده PGlite (پیش‌فرض: `.data/pg`) |
| `HOST` | آدرس bind سرور production (پیش‌فرض: `0.0.0.0`) |
| `PORT` | پورت سرور production |
| `COOKIE_SECURE` | برای HTTPS مقدار `true`، برای HTTP ساده `false` |
| `AI_BASE_URL` | آدرس سازگار با OpenAI برای فعال‌سازی AI |
| `AI_API_KEY` | کلید API (اختیاری) |
| `AI_MODEL` | نام مدل |

اگر متغیرهای AI تنظیم نشوند، همه‌چیز با موتور قطعی کار می‌کند. خروجی AI قبل از ذخیره اعتبارسنجی می‌شود و در صورت نامعتبر بودن، برنامه قطعی جایگزین می‌شود.

## اسکریپت‌ها

| فرمان | کار |
|---|---|
| `bun run dev` | اجرای محیط توسعه |
| `bun run build` | ساخت production |
| `bun run start` | اجرای build |
| `bun run typecheck` | بررسی TypeScript |
| `bun run test` | تست‌های واحد (Vitest) |
| `bun run db:seed` | ساخت داده نمونه |
| `bun run db:seed:analysis` | افزودن ۲۰ دانش‌آموز و ۴ ماه داده مطالعه/آزمون نمونه |
| `bun run db:export:example` | خروجی JSON از داده‌های فعلی در `data/example/` |
| `bun run db:import:example` | بارگذاری داده‌های `data/example/` در دیتابیس |
| `bun run db:reset` | حذف `.data` و بازنشانی دیتابیس |

### استفاده از داده نمونهٔ آماده

در `data/example/` یک اسنپ‌شات JSON از داده‌های نمونه نگهداری می‌شود:

- ۲۰ دانش‌آموز و یک مشاور
- منابع پایه‌های دهم، یازدهم و دوازدهم
- حدود ۴ ماه برنامه و دفترچه عملکرد
- ۸۰ کارنامهٔ آزمون بیرونی و آزمون‌های درون سامانه

#### بازسازی دیتابیس از صفر

```bash
bun install
bun run db:reset
bun run db:import:example
bun run dev
```

سپس `http://localhost:3000` را باز کنید. رمز عبور همهٔ کاربران نمونه `seemorgh123` است و شماره موبایل‌ها در `data/example/users.json` قرار دارد.

#### ذخیرهٔ داده‌های فعلی به‌عنوان نمونه

اگر داده‌ها را تغییر دادید و می‌خواهید همان‌ها را برای دیگران ذخیره کنید:

```bash
bun run db:export:example
```

#### ساخت داده‌های تحلیلی نمونه

برای افزودن دوبارهٔ ۲۰ دانش‌آموز و ۴ ماه دادهٔ مطالعه/آزمون:

```bash
bun run db:seed:analysis
```

> فایل‌های `data/example/` فقط داده هستند؛ خود دیتابیس در `.data/pg` قرار می‌گیرد و در git ذخیره نمی‌شود.

## قابلیت‌ها

### مشاور
- ساخت دانش‌آموز و لینک دعوت
- تعریف/ویرایش/حذف منابع در تب **منابع** هر دانش‌آموز: درس، عنوان، تعداد کل، پیشرفت اولیه، اولویت و **فصل‌بندی**
- به‌روزرسانی خودکار پیشرفت منبع از روی گزارش عملکرد دانش‌آموز
- تب **وضعیت منابع** با نمودار کلی، میله‌ای هر منبع/درس، نمودار دایره‌ای سهم درس‌ها و مسابقهٔ لاک‌پشت
- تب **تحلیل آزمون**: کارنامه‌های درون سامانه، ثبت دستی یا OCR آزمون‌های بیرونی، تحلیل یک آزمون و تحلیل روند ۴ ماهه
- زمان‌های آزاد، روز تعطیل، سقف روزانه و بافر
- پنل برنامه‌ریزی با بازه‌های دو ساعته از ۸ تا ۲۰ (شامل ۱۶–۱۸ و ۱۸–۲۰)
- ساخت پیش‌نویس برنامه هفتگی با موتور قطعی یا **AI اختیاری**
- ویرایش/جابه‌جایی تسک، تأیید برنامه، بازتولید پیش‌نویس
- گزارش بازه‌ای (از/تا) با تحلیل عملکرد، **ساعت شروع هر روز** و گزارش تحلیلی (قطعی یا AI)
- بانک سوال اختصاصی
- ساخت آزمون گروهی با blueprint، گزینش قطعی یا **AI اختیاری**
- انتشار آزمون با snapshot، تصحیح MCQ و کوتاه‌پاسخ، کارنامه و p-value
- کتابخانه محتوا: فیلم آپارات، متن و تست روان‌شناسی به‌صورت لینک
- اعلان درون‌برنامه‌ای و تاریخچه تغییرات (audit)

### دانش‌آموز
- نمای «امروز»: تسک‌های امروز به‌صورت نمایشی، پیام شروع و هشدار عقب‌افتادگی (بدون ثبت داده)
- **دفترچه عملکرد**: تنها محل ثبت شروع/پایان، تمرین و پیشرفت منابع
- **منابع من**: تعریف/ویرایش/حذف منابع اختصاصی دانش‌آموز
- **گزارش من**: تحلیل عملکرد و ساعت شروع هر روز برای بازه انتخابی + گزارش تحلیلی
- **وضعیت منابع**: نمودار پیشرفت کلی، هر درس، هر منبع و سهم درس‌ها
- **تحلیل آزمون**: ثبت کارنامه، تحلیل سختی هر درس در آزمون و تحلیل روند علمی
- آزمون زمان‌دار: ذخیره خودکار، تحویل خودکار، کارنامه
- محتوای مرتبط با هر منبع + پخش ویدیو داخل سایت
